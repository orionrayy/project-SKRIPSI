# Academic Quality Assurance Matrix

Use this matrix for every thesis project. Record the exact artifact and result for each applicable row. `NOT_APPLICABLE` requires a reason; `NOT_RUN` is not a pass.

| Gate | What is checked | Evidence required | Reviewer |
|---|---|---|---|
| Scope and rubric | Questions, deliverables, campus rubric and version | Intake checklist and rubric source | Student + operator |
| Literature | Source quality, search transparency, synthesis, relevance and gap | Search log, source register, synthesis matrix | Research reviewer |
| Argument | Problem–question–objective–hypothesis alignment | Traceability matrix | Academic reviewer |
| Method | Design fit, population/sample/case, instruments, protocol, analysis plan | Methodology profile and instrument evidence | Qualified method reviewer |
| Ethics and privacy | Permissions, consent, data minimization, storage and retention | Approval/permission records and data plan | Institution/ethics authority where required |
| Data provenance | Origin, collection/processing history, checksums, missingness and transformations | Dataset manifest and processing log | Data reviewer |
| Statistics/analysis | Appropriate method, assumptions, diagnostics, reproducibility and interpretation | Analysis run record, scripts/settings, outputs and diagnostics | Qualified statistical reviewer |
| Citations | Claim-to-source support, quote accuracy, bibliography parity | Claim register, source locators, reference audit | Editor/reviewer |
| Writing | Clarity, discipline-specific register, coherent reasoning and non-repetition | Draft, style checklist and author review | Student + editor |
| Document compliance | Current campus template, section order, tables/figures, page layout | Versioned guideline profile and rendered review | Student + editor |
| Final accountability | Student can explain decisions, data, method and conclusions | Defense rehearsal and signed final decision | Student + supervisor |

Similarity percentages and AI detector scores are not quality gates. Similarity tools can help locate matching text; they do not establish plagiarism by themselves. Never promise a target score or evade detection. Human review and institutional rules govern disclosure and acceptance.
